# Third-party sources

- Source: https://github.com/cyberbotics/webots/tree/R2025a/projects/humans/pedestrian
- Version: R2025a (matching the installed simulator).
- `webots/protos/vendor/Pedestrian*.proto`: Cyberbotics pedestrian model and geometry; original headers retained; trailing empty lines normalized. These assets are **licensed for use only with Webots**, per https://cyberbotics.com/webots_assets_license . The upstream Webots repository's general Apache license does not override these asset headers.
- `webots/controllers/assistive_walker/upstream_pedestrian.py`: official Python pedestrian controller, Copyright 1996–2024 Cyberbotics Ltd., Apache License 2.0. Adaptation: wrapped its original entrypoint in `if __name__ == '__main__'` so the gait class can be reused. Original license notice retained. https://www.apache.org/licenses/LICENSE-2.0
- Buildings, road, sidewalk, urban props, car, rig and cane: generated from native Webots primitives in `webots/scripts/build_world.py`. Texture pixels and unbranded surface panels and warning graphics are generated by `webots/scripts/build_textures.py`; Korean text uses the installed Noto Sans CJK font. No third-party street photos or AI image assets were imported.
- The stereo implementation uses the installed OpenCV StereoSGBM/calibration APIs: https://github.com/opencv/opencv .
- Speech uses the installed system `libespeak-ng` and Korean language data through its public C API. https://github.com/espeak-ng/espeak-ng

- YOLO26 detection is an optional dependency from Ultralytics: https://github.com/ultralytics/ultralytics . Upstream package/model licensing is described at https://docs.ultralytics.com/models/yolo26/ (AGPL-3.0 or Enterprise). Weights are explicitly downloaded locally and are not committed.
